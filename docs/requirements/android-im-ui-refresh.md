# Android IM 化界面改版需求

## 背景

当前 Android 客户端已经具备最小闭环能力，但界面仍偏向调试面板：

- 双栏布局更像桌面控制台，不适合手机单手使用
- 会话列表缺乏 IM 联系人感
- 消息区缺乏明显的聊天时间线层次
- hub 地址配置直接暴露在主界面顶部，干扰主要任务
- 状态、命令、产物的视觉层级不清晰

这会削弱产品定位，使其看起来像一个内部测试工具，而不是“个人私有 Agent IM / Agent Control Client”。

## 目标

在不改变现有协议与核心逻辑的前提下，将 Android 客户端改造成更接近 IM 的移动端体验。

## 设计要求

- 默认采用手机优先的单列结构
- 先看到 agent 列表，再进入单独会话页
- 会话页应具备明显的顶部栏、消息流和底部输入区
- agent 状态应以更清晰的视觉标签呈现
- 快捷命令应以轻量操作条呈现，而不是调试按钮墙
- 图片产物应在时间线中展示预览
- hub 地址配置应收纳到二级设置区域，不占据主阅读区
- 界面风格应明确区别于“远程终端套壳”

## MVP 范围

- 重构主界面为 IM 风格的列表页与会话页
- 引入更清晰的视觉主题和状态色
- 优化消息卡片、产物卡片、快捷命令条和输入区
- 保持现有连接、轮询、命令与调试能力不变

## 非目标

- 不引入完整导航框架重构
- 不加入用户账号体系
- 不加入复杂动效和自定义绘制
- 不改变底层协议模型
