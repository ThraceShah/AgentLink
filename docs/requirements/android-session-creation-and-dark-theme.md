# Android 新建会话与深色模式优化需求

## 背景

当前 Android 客户端已经支持通过首页创建新的 tmux-backed agent 会话，但仍存在以下问题：

- 首页顶部 `New` 与 Hero 卡片内的 `Create tmux session` 功能重复。
- 新建会话时只能输入会话名，无法同时指定工作目录。
- 深色模式下部分卡片与文字的对比度偏低，可读性不足。

这些问题会直接影响日常使用效率，也会削弱客户端作为“个人私有 Agent IM”的产品感。

## 目标

本次优化需要完成以下目标：

1. 首页只保留一个“新增会话”入口，避免重复操作点。
2. 新建会话时支持指定工作目录。
3. 工作目录默认创建在当前用户的 `code/` 目录下，但应允许通过配置修改根目录。
4. 会话目录支持多层相对路径，例如 `tests/first_test`。
5. 若目标目录不存在，应自动创建；若已存在，则直接复用。
6. 创建 tmux 会话时，应以该目录作为工作目录。
7. Android 弹窗中需要用小字明确提示目录最终会创建在什么位置。
8. 优化深色模式配色，提高文字、卡片与背景之间的对比度。

## 非目标

- 本次不引入完整的文件选择器。
- 本次不支持任意绝对路径输入。
- 本次不新增多 profile 的复杂工作目录模板能力。
- 本次不调整 Android 的整体导航结构。

## 功能要求

### 1. 首页入口

- 保留顶部导航栏中的 `New`。
- 删除 Hero 卡片中的重复创建按钮。

### 2. 新建会话参数

创建会话弹窗至少包含：

- agent profile 选择
- session name
- workdir

其中：

- `workdir` 为相对路径
- 允许输入 `test`、`tests/first_test` 这类路径
- 不允许输入绝对路径
- 不允许通过 `..` 跳出工作目录根路径

### 3. 后端行为

- Hub 提供一个可配置的工作目录根路径。
- 默认值为当前用户 home 下的 `code/` 目录。
- 创建会话时：
  - 先解析最终目录
  - 确保目录存在
  - 若不存在则递归创建
  - 再在该目录中创建 tmux session

### 4. UI 提示

- 弹窗中应明确展示“该目录会创建在……”的提示文本。
- 该提示文本使用较弱强调的小字样式，但必须可读。

### 5. 深色模式优化

- 提高背景与卡片层之间的亮度差异。
- 提高次级文字颜色亮度，避免信息发灰看不清。
- 输入框、会话卡片、信息卡片的边界应更清晰。

## 验收标准

- 首页只剩一个新增会话入口。
- 新建会话时可同时填写 session name 和 workdir。
- 输入 `tests/first_test` 后，Hub 能在默认根目录下创建对应层级目录并启动 tmux 会话。
- 已存在目录可正常复用。
- 深色模式下主要文字、次级说明、卡片边界均明显更易读。
