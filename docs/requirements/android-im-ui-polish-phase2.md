# Android IM 界面第二轮精修需求

## 背景

第一轮 Android UI 改版已经把客户端从调试面板重构为更接近 IM 的结构，包括：

- 单列 Inbox
- 独立会话页
- 底部输入区
- 状态胶囊

但当前界面仍然偏粗糙，主要问题包括：

- Inbox 卡片的信息层级还不够成熟
- 关键状态缺少全局摘要
- 会话页消息卡片还不够像成品消息流
- 视觉节奏仍偏“工程可用”，未达到“自用工具顺手耐看”

## 目标

在不改变协议和核心交互的前提下，对 Android 客户端做第二轮视觉与交互精修，使其更接近成熟的 Agent IM。

## 设计要求

- Inbox 顶部应具备更清晰的系统摘要
- agent 卡片应更接近联系人/会话卡片，而不是普通信息卡
- 会话页消息流应具备更明确的类型标签和层次
- 空态和辅助信息应更自然
- 保持移动端优先，不回退到双栏或调试面板布局

## MVP 范围

- 增强 Inbox 顶部概览区
- 优化 agent 会话卡片样式与摘要信息
- 优化消息气泡、事件标签和空态
- 保持当前连接、调试和命令能力不变

## 非目标

- 不引入复杂动画系统
- 不引入消息数据库
- 不引入未读同步或通知中心重构
- 不改变当前 Kotlin/Compose 技术栈
