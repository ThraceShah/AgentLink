# Android 会话操作与复制体验优化

## 背景

当前 Android 客户端已经具备基本会话能力，但在高频使用中仍存在以下问题：

1. 会话卡片无法直接在列表页删除，清理成本高。
2. 某些会话页面在实时连接不可用时会显示 `Polling` 相关状态，当前排版与视觉层级较差。
3. 会话页顶部和底部仍保留了 `status`、`stop`、`retry` 这类协议/能力标签，占用空间且与 IM 型交互不匹配。
4. 卡片内容与消息内容不支持复制，不利于在手机上复用指令、报错和结果。
5. 文档中仍存在部分过时表述，需要与当前交互方式保持一致。

## 目标

本轮优化目标如下：

1. 在会话卡片列表中支持删除入口。
2. 会话页清理冗余标签，保留更像 IM 的输入体验。
3. 将底部命令交互调整为 slash command 风格，而不是常驻命令按钮。
4. 会话卡片与消息内容支持复制。
5. 修正实时连接降级状态在页面中的视觉表达，使其更易读。
6. 同步更新正式文档，避免保留已经失效的 UI 说明。

## 范围

本次范围包含：

- Android 首页会话卡片交互
- Android 会话页头部与底部输入区
- Android 消息卡片复制能力
- 与当前 UI 行为相关的 README / guide / changelog 更新

## 具体要求

### 1. 会话卡片删除

- 首页会话卡片应支持左滑删除。
- 首页会话卡片也应支持长按后弹出删除选项。
- 删除前必须二次确认，避免误删。
- 删除后应调用现有删除 session 能力，并同步从 UI 中移除该卡片。

### 2. 会话页状态展示

- 会话标题栏不再展示 `status`、`stop`、`retry` 等标签。
- 会话页头部不再展示 capability 标签列表。
- 实时连接状态若为轮询降级，应使用更紧凑、更易读的表达，避免长文字挤压布局。

### 3. slash command 输入

- 底部不再展示快捷命令按钮。
- 输入框应支持直接输入 slash command，例如 `/status`、`/retry`、`/stop`。
- 若当前 agent 支持的命令不同，应根据该 agent 的可用能力动态提示可用 slash command。
- 非 slash command 输入继续按普通文本消息发送。

### 4. 复制能力

- 长按会话卡片时，除删除入口外，还应允许复制卡片预览内容。
- 长按消息气泡时应复制该条消息的主要文本内容。
- 若为图片/artifact 消息，应至少支持复制 caption 或文件名摘要。
- 复制成功后应提供轻量反馈。

## 非目标

- 不在本轮实现多选批量删除。
- 不在本轮实现消息转发、收藏、搜索。
- 不在本轮实现系统级分享面板集成。
- 不在本轮实现富文本编辑器或命令自动补全弹层。

## 验收标准

1. 首页任一会话卡片可通过左滑或长按进入删除流程。
2. 会话页顶部不再出现 `status`、`stop`、`retry` 等协议标签。
3. 会话底部不再显示快捷命令按钮，而是通过 slash command 承载命令输入。
4. 长按卡片与长按消息均可复制有效内容。
5. 降级状态下页面排版保持稳定、可读，不出现明显拥挤或错位。
