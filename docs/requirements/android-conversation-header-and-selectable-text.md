# Android 会话头部与选择复制优化需求

## 背景

当前 Android 客户端的会话页仍存在两个明显体验问题：

1. 顶部状态区域仍以独立卡片呈现，占据首屏空间，且 `Live` 等连接态文案在窄宽度下会发生换行，影响观感。
2. 消息复制仍以“整段直接复制”为主，不支持用户像 IM 一样通过选择光标自定义复制内容。

这两个问题都会降低会话页的 IM 感和细节完成度，需要一并修正。

## 目标

- 移除会话页顶部独立状态卡片。
- 将 agent 类型、会话状态、连接状态合并到会话名称下方的一行信息中。
- 连接状态不再显示 `Live`、`Fallback` 等文字，而是改为颜色圆点提示。
- 消息长按后进入可选文本模式，默认选中整条消息文本，允许用户拖动选择范围。
- 保持会话页整体更紧凑，避免重复状态标签和排版拥挤。

## 功能要求

### 1. 会话头部信息重排

- 会话页顶部保留会话名称。
- 在会话名称下方增加一行元信息：
  - 左侧显示 agent 名称或类型；
  - 右侧显示当前会话状态；
  - 状态旁使用单个小圆点表示连接态。
- 不再显示 `Status:` 前缀。
- 不再保留原先独立的状态卡片。

### 2. 连接状态展示

- `connected`、`connecting`、`disconnected` 分别映射为不同颜色的小圆点。
- 圆点仅用于提示连接态，不再显示对应文本。
- 圆点应保持单行显示，不得挤压标题导致换行错位。

### 3. 消息选择复制

- 消息气泡长按后，不应直接整段复制到剪贴板。
- 应进入可选文本模式，默认选中整条文本。
- 用户可通过系统选择光标调整选区后再复制。
- 对无正文但有 artifact 描述的消息，也应提供同样的选择能力。

## 非目标

- 本轮不改动会话协议和消息结构。
- 本轮不改动首页卡片样式。
- 本轮不引入富文本、Markdown 选择复制或局部翻译能力。

## 验收标准

- 会话页首屏不再出现独立状态卡片。
- 标题下方元信息保持单行、无明显拥挤或断裂。
- `Live`、`Fallback` 文案不再出现，连接态仅通过圆点区分。
- 长按消息后可进入文本选择界面，默认全选整条消息，并可自由拖动复制部分文本。
- 使用本机 Android 模拟器完成安装、自测和截图检查，确认无明显排版问题或重复信息。
