# 移动 Web 聊天导航需求

## 背景

移动 Web 是单页应用，但此前进入聊天页时没有写入浏览器历史。用户使用浏览器返回或 Android 系统返回会直接退出 Web 应用，而不是返回会话主页。长会话默认滚动到底部后，顶部返回、删除等操作也不容易触达。

## 目标

- 从会话列表进入聊天页时写入浏览器历史状态。
- 在聊天页触发浏览器返回或 Android 系统返回时，应返回会话列表，而不是退出 Web 应用。
- 聊天页底部必须提供常用导航入口，避免长会话中必须滚到顶部才能回到主页。
- 聊天页底部应提供跳到顶部能力，便于访问顶部操作。

## 非目标

- 不改变 Hub 会话生命周期。
- 不引入路由框架。
- 不改变现有顶部返回和删除按钮语义。

## 验收标准

- 点击会话进入聊天页后，浏览器返回键回到会话列表。
- 在聊天页点击底部返回入口回到会话列表。
- 在聊天页点击底部跳顶入口，时间线滚动到顶部。
- 直接打开主页时，浏览器返回仍按浏览器默认行为处理。
- `node --check apps/mobile-web/app.js`、`npm test`、`npm run build` 通过。
