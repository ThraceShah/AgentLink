# 会话底部上下文状态栏需求

## 背景

当前 Android 会话页已经有运行态信息栏，但存在以下问题：

- 信息栏位于输入框上方，视觉重心过高，会挤压对话区。
- 使用了多个胶囊标签，样式偏重，不符合当前 IM 风格。
- 同时显示模型名、上下文占用和窗口大小，其中模型名已经在消息标签中出现，信息重复。

## 目标

将会话运行态信息收敛为一条更轻、更低干扰的底部状态栏，强调“上下文占用”这一条对 agent 使用最有价值的信息。

## MVP 范围

- 状态栏移动到消息输入框下方，也就是会话页最底部。
- 状态栏高度尽量压低，文字尺寸使用小号样式。
- 状态栏只使用纯文本展示，不再使用标签、胶囊或按钮式控件。
- 状态栏不再显示模型名称。
- 状态栏展示最近一次有效运行数据中的上下文占用，格式为：
  - `128k/256k`
  - `128k/NA`
  - `NA/NA`
- 若可获取真实上下文窗口大小，优先显示真实窗口值；否则显示 `NA`。

## 非目标

- 不在本次改动中调整消息气泡中的模型标签逻辑。
- 不在本次改动中新增更复杂的 token 明细面板。
- 不在本次改动中修改 hub 协议结构。

## 验收标准

- 打开任意会话页，输入框下方可以看到一条细窄的纯文字状态栏。
- 状态栏不会出现胶囊、标签式边框或额外按钮。
- 状态栏默认不显示模型名。
- 在已有 usage metadata 的会话中，状态栏能显示 `已用/窗口` 形式的上下文信息。
- 在窗口大小未知时，状态栏能稳定显示 `NA`，而不是空白或异常文案。
